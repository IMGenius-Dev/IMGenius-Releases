# IMGenius — Offline AI Character Chat & Roleplay

**IMGenius** is a desktop app for AI character chat, creative roleplay, and storytelling on **Windows and Linux**. Create original characters, import character cards, and chat using language models installed on your own computer through **Ollama**. Optional **ComfyUI** integration adds local image-generation features.

**[Explore the website](https://imgenius-dev.github.io/IMGenius-Releases/)** · **[See the features](https://imgenius-dev.github.io/IMGenius-Releases/features.html)** · **[Download IMGenius](https://github.com/IMGenius-Dev/IMGenius-Releases/releases)**

## Features

- **AI character conversations:** Chat with characters you create or import, with personalities, descriptions, and custom greetings.
- **Creative roleplay:** Build fictional scenarios, explore stories, and choose the local language model you want to use.
- **Character creation tools:** Edit character cards, keep descriptions and personalities organized, and draft character details with a selected local model.
- **Conversation controls:** Continue or regenerate responses, edit messages, and choose alternate opening greetings.
- **Optional AI images:** Connect a compatible local ComfyUI installation for image generation alongside chat.
- **Personalization:** Choose from dark, pastel, galaxy, Catppuccin, and Pride-inspired themes.

## Offline chat and privacy

**Local character chat works without an internet connection once IMGenius, Ollama, and a compatible language model are installed.** Conversations and character data are saved on your own device, and IMGenius does not automatically upload your chat content or character cards to us.

An internet connection is needed to download the app, models, or optional online content. If you choose to browse external model catalogs or submit a support report, those actions use the relevant online services. See the [privacy page](https://imgenius-dev.github.io/IMGenius-Releases/privacy.html) for details.

## Getting started

1. Download and install the IMGenius package for your operating system.
2. Install **Ollama** and download a compatible language model.
3. Open IMGenius, choose your local model, and create or import a character.
4. Start chatting. You can disconnect from the internet for local conversations after completing setup.

**Ollama and a downloaded language model are required for chat.** IMGenius does not include model weights. ComfyUI and image models are optional and only needed for image-generation features.
