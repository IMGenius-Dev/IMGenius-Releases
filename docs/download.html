BEFORE YOUR FIRST CHAT

A little setup. A lot of stories.

IMGenius does not bundle Ollama language models or ComfyUI image checkpoints. Install Ollama and download a compatible language model for local AI character chat. ComfyUI is optional if you want image features.

Read the release notes for version-specific requirements. For safety, get installers only from the official release page and do not bypass unexpected security warnings.
