FREQUENT QUESTIONS

Good to know.

Is IMGenius an AI roleplay chatbot?

IMGenius is a desktop AI character-chat and roleplay application. You create or import character cards and chat through a local Ollama language model.

Can I create an AI companion?

You can make characters with personalities and backstories for fictional interactions and companion-style conversation. IMGenius is a creative chat tool, not a substitute for real-world care or relationships.

Can IMGenius support mature or NSFW roleplay?

IMGenius does not bundle language models. Whether mature themes are supported depends on the local model you choose and its configuration, usage terms, and applicable laws. No specific outputs are guaranteed.

Can I use IMGenius completely offline?

Yes, for local character chat: once IMGenius, Ollama, and a compatible model have been installed, you can disconnect from the internet and keep chatting. Online model catalogs, downloads, updates, and optional support reporting need a connection. The app may attempt a GitHub update check when online; this is separate from local conversation inference.

Does IMGenius collect or read my conversations?

IMGenius does not include automatic chat-content collection or developer-run cloud inference for local chat. Character cards and chats are stored on your computer. If you choose to submit an issue report, only the report details and files you select are sent to the configured support service. More privacy details →

Does IMGenius include AI models?

No. You install the Ollama language models you want to use. Optional image generation requires a separate compatible ComfyUI installation and image models.
