HOW LOCAL AI WORKS

You choose the language model.

IMGenius uses local Ollama inference for character dialogue. Install Ollama, download a compatible model, and connect your chat studio to it.

After downloading a compatible model, local chatting works even when your computer is disconnected from the internet. The app does not automatically collect local roleplay conversations. Different models still vary in style, requirements, and content restrictions; mature content depends on the model you choose.

AN OPEN BETA

What to expect.

Where is my roleplay chat data stored?

Chats and character cards are stored in your local IMGenius user-data directory. IMGenius does not automatically upload their contents to the developer. Optional connected services and user-submitted issue reports are separate; see the privacy page.

Does IMGenius run AI models in the cloud?

The current public beta uses local Ollama for language-model responses. Optional tools may need internet access to download software, models, or updates.

Is image generation required?

No. You can use character chat without ComfyUI. Local image generation is optional and requires separate compatible dependencies and image models.

Is IMGenius free to try?

Public beta installers are currently offered through GitHub Releases. Check the release notes for the supported platforms, exact assets, and requirements.
